# LeetCode Solutions

A personal repository that automatically tracks my **LeetCode
submissions** and keeps a record of my problem-solving journey. Instead
of relying on memory or manually updating a progress list, this project
helps maintain a running history of the problems I solve.

The goal is simple: **track consistency, measure progress, and build a
transparent record of my DSA journey.**
